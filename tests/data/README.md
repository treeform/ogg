# Small reference corpus

These files are original synthetic media generated by `tools/gen_media.py`.
There are no downloaded songs, films, or third-party media excerpts.

| File | Coverage |
| --- | --- |
| mono.ogg | 22050 Hz mono, 5512 samples, short final packet |
| stereo.ogg | 48000 Hz stereo, 12000 samples, different tones and amplitudes |
| silence.ogg | 8000 Hz mono, 2000 samples, exact silence |
| continued.ogg | 48000 Hz mono, 12000 samples, comment packet spanning pages |
| video420.ogv | 64 by 48, 12 fps, 6 frames, 4:2:0 |
| video422.ogv | 64 by 48, 12 fps, 6 frames, 4:2:2 |
| video444.ogv | 64 by 48, 12 fps, 6 frames, 4:4:4 |
| mixed.ogv | 82 by 50 visible picture, padded coded dimensions, stereo audio |

Audio is a 440 Hz sine wave at amplitude 0.25 in channel one and a 660 Hz sine
wave at amplitude 0.125 in channel two. Video is moving colored bars with a dark
checker pattern. The mixed clip is 0.5 seconds long with 24000 audio sample frames.

The `.f32` files contain interleaved little-endian float PCM. The `.yuv` files
contain all visible frames in planar Y, Cb, Cr order at the original subsampling.
They are decoded by FFmpeg's native Vorbis and Theora implementations, not by
this repository's bundled libraries.

For audio, the generator requests FFmpeg's manual skip handling, removes the
first packet's warm-up samples, then retains the known original sample count.
The initial skip and final lengths are recorded in the manifest. This avoids
FFmpeg's default short-file trimming differences without shifting the waveform
or accepting a shorter comparison. The C reference must independently produce
the full source sample count using Vorbis granule semantics.

Tests compare every sample with RMS error below 0.000001 and maximum error below
0.00001. All visible YCbCr values are compared with maximum difference 2 and mean
difference below 0.1 to allow independent integer transform rounding.

`manifest.json` records the exact generation commands, FFmpeg version, metadata,
and SHA-256 checksums. Encoder and FFmpeg versions can change encoded bytes. The
checked-in files and manifest are the fixed oracle. Regeneration is an intentional
corpus update and should be reviewed with its manifest changes.

```sh
python tools/gen_media.py --verify
python tools/gen_media.py
nim r tests/tests.nim
```

Ordinary tests need neither FFmpeg nor network access. Tests construct corrupt,
truncated, checksum-correct sequence-gap, unsupported-codec, and chained variants
in memory. This is a starting corpus, not the full official conformance suite.

All generated media and decoded reference files in this directory are dedicated
to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
